# Initial Sources

This is a curated starting list, not a complete transcription. Check each page and author metadata before adding detailed claims.

## SoundQuest — 自由派音楽理論
- https://soundquest.jp/
- Human-authored educational music-theory resource; verify author and date per page.
- Useful areas: chord functions, secondary dominants, borrowed chords, substitutions, voice leading and reharmonization.

## SRM Music — 音楽理論メールレッスン
- https://srm-music.com/music-theory-mail-lesson/
- Human-authored educational resource; verify author and date per lesson.
- Use for accessible explanations and practical examples.

## するめミュージック — おしゃれコード進行
- https://srm-music.com/stylish-chord/
- Human-authored music education article; verify author metadata.
- Use for chord colors, vertical/horizontal reharmonization and practical progressions.

## Reo — 弾くだけでいい曲になるコード進行10選
- https://www.youtube.com/watch?v=7uGntdbswYk
- Human-created tutorial. Check licensing before reusing accompanying MIDI.
- Use for common pop progressions and practical MIDI examples.

## ChordWiki
- https://chordwiki.org/
- User-contributed chord chart database. Treat transcriptions as unverified until checked; respect site terms and copyright.

## ChordTube
- https://chordtube.net/
- Future interoperability target. Search using normalized chord symbols / Roman numerals. Do not assume a public API exists until verified.

## Source policy
Public availability does not automatically grant redistribution rights. Do not copy full articles, lyrics, sheet music or proprietary MIDI into this repository. Keep source facts separate from project heuristics.
